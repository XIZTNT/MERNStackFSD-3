1. Components
Components are functional pieces of the Javascript functions that allow users to interact in various ways through a website's development. Components can also receive information and display whatever needs to appear such as video content. 
2. Props
Props, or properties, are a way to have data pass to components that are similar to function arguments in JS with HTML attributes.

3. State

State is an object used to store data or properties that belong to a component and can change over time.
